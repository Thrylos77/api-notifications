# Django Notifications Project

## English

### 📌 Overview
This project is a **Django-based application** that provides a flexible **notification system** for web applications.  
It includes:
- Storage of notifications in the database
- Email notifications (via SMTP)
- Real-time updates with WebSocket or polling
- Read/unread status management for users

### 🚀 Features
- Notification model with types and status
- API endpoints for notifications
- Email integration using Django’s email backend
- Admin panel for managing users and notifications

### 🛠️ Requirements
- Python 3.10+
- Django 5+
- SQLite (default) or PostgreSQL/MySQL
