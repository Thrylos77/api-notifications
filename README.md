# Notifications API

## Description

This project contains backend implementations for a notification API. The goal is to provide a robust and flexible notification service that can be integrated with various applications.

Each subfolder in this project contains an implementation of the API with a specific framework. You will find a detailed `README.md` in each folder for installation and usage instructions specific to that technology.

## General Features

Regardless of the framework used, the notification API aims to provide the following features:

-   **Notification Creation**: Allows applications to send notifications to users or groups of users.
-   **Status Management**: Tracking of notifications (read, unread).
-   **Flexibility**: Easily adaptable to different types of notifications (alerts, information, messages, etc.).

## Implementations

-   `django-notifications/`: Implementation with Django and Django Rest Framework.

Please refer to the `README.md` in each folder for more details.
